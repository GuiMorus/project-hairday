# ✂ Projeto - Hairday

Já imaginou poder marcar um horário em um salão de beleza de forma simples e rápida? Esse projeto é uma aplicação de agendamento de horários para um salão, permitindo consultar os horários disponíveis e realizar novos agendamentos.

A aplicação verifica os horários já cadastrados e disponibiliza apenas aqueles que ainda estão livres. Cada novo agendamento é salvo em um servidor utilizando **JSON Server**, contendo o nome do cliente, a data e o horário escolhido.

## 💡 Comentários

Gostei bastante de desenvolver este projeto porque ele acabou sendo um dos projetos mais completos que fiz até agora.

Durante o desenvolvimento, precisei trabalhar com várias partes diferentes de uma aplicação, desde a manipulação do **DOM** e dos formulários até a comunicação com um servidor utilizando **JSON Server**.

Também foi a primeira vez que trabalhei de forma mais completa com ferramentas como **Webpack** e **Babel**, além de utilizar o **Day.js** para trabalhar com datas e horários.

A aplicação não apenas exibe informações, mas possui uma lógica real de funcionamento: ao acessar o sistema, os horários já cadastrados são consultados no servidor e os horários disponíveis são identificados para que novos agendamentos possam ser realizados.

Sinto que este projeto me ajudou a sair um pouco daquela bolha de saber apenas o básico de **HTML, CSS e JavaScript**. Cada vez mais começo a entender como diferentes ferramentas e tecnologias se conectam para construir uma aplicação completa.

Isso também me faz sentir cada vez mais próximo de conseguir desenvolver **aplicações reais, que possuem uma finalidade e funcionam no dia a dia como um sistema de trabalho de verdade**.

## 📚 Aprendizados

Neste projeto pratiquei:

- **Webpack:** configuração e organização do processo de desenvolvimento e empacotamento da aplicação.
- **Babel:** utilização de transpilação para permitir o uso de recursos modernos do JavaScript.
- **Day.js:** manipulação de datas e horários e verificação dos horários disponíveis para agendamento.
- **JSON Server:** criação de um servidor local para armazenar e disponibilizar os agendamentos.
- **Fetch API:** comunicação entre a aplicação e o servidor para buscar e enviar informações.
- **API e JSON:** consumo, envio e manipulação de dados vindos de uma API.
- **DOM (Document Object Model):** seleção, criação e manipulação de elementos HTML.
- **Event Listeners:** gerenciamento de eventos e interações realizadas pelo usuário.
- **Formulários:** captura, validação e envio de informações inseridas pelo usuário.
- **Renderização dinâmica:** criação e atualização dos horários disponíveis diretamente na interface.
- **Manipulação de datas:** comparação entre horários e datas para determinar quais horários podem ser agendados.
- **JavaScript modular:** divisão da aplicação em diferentes arquivos e módulos para melhorar a organização e manutenção do código.
- **Organização de projetos:** separação de arquivos, códigos e responsabilidades em diferentes diretórios.
- **JavaScript moderno (ES6+):** utilização de recursos modernos da linguagem.
